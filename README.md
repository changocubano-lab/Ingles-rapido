# Inglés rápido · Inglês rápido

Free phone app to help Spanish and Portuguese speakers learn English: a 30-day step-by-step course, a sounds guide, a tool that shows how to read any English word, phrases, dialogues and quizzes with audio.

- Español: https://changocubano-lab.github.io/ingles-rapido/es/
- Português: https://changocubano-lab.github.io/ingles-rapido/pt/
